# Limpia-Mar

Videojuego 2D de laberinto, hecho en **Python con pygame**. El jugador controla a Aspi, una aspiradora submarina que recorre un arrecife: cada basura que aspira suma puntos y cada pez que se traga resta muchos. El nivel se gana al limpiar toda la basura antes de que se acabe el tiempo.
